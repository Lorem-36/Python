# 🎓 Student Grade Manager

A beginner-friendly Python mini-project that collects a student's marks, validates the entered marks, calculates the total and average, and determines the student's grade.

This project was created as part of a Python learning journey to practice lists, loops, functions, input validation, conditional statements, parameters, and return values.

## 🎯 Objective

The objective of this project is to create a simple student grade management program.

The program asks the user for:

- Student name
- Number of subjects
- Marks for each subject

It then:

1. Validates every mark.
2. Stores valid marks in a list.
3. Calculates total marks.
4. Calculates average marks.
5. Determines the student's grade.

---

## ✨ Features

- Takes student name as input.
- Takes the number of subjects.
- Accepts marks for each subject.
- Validates marks between `0` and `100`.
- Rejects invalid marks.
- Uses a `while` loop for repeated input.
- Stores marks in a list.
- Calculates total marks.
- Calculates average marks.
- Determines the grade.
- Uses separate functions for different operations.
